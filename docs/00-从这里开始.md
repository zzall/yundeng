# 从这里开始

这是一份「我自己从零做出一款网页小游戏」的完整复盘包。所有内容都基于真实产物
`E:\project\aigames\云灯\云灯.html`（已上线的那款《云灯 · 守灯人七夜》），不是教程抄来的示例。

## 你会得到什么

- 一份**资源清单**：我实际用到的库、网站、开源项目，以及每个东西「用来干什么、什么时候该看」。
- 一份**拆解笔记**：一个网页游戏到底由哪几块拼起来，代码在哪一行。
- **两个可双击打开的小 demo**：把最关键的两段技术单独做成能跑的最小版本。
- **上线清单**：本地能玩 → 能发给朋友 → 能上小游戏平台，每一步的门槛是什么。
- **进阶地图**：什么时候该换引擎、换哪个、别踩哪些坑。

## 三条学习路线（按你有的时间选）

**路线 A｜30 分钟，只想搞懂原理**
1. 读 `02-拆解云灯.md` 的「一张图看懂」和「六个机制」。
2. 双击 `demo\01-接光小游戏.html` 玩 3 分钟，再看它的源码（200 行左右）。

**路线 B｜3 小时，想自己能改**
1. 路线 A 全部。
2. 打开 `E:\project\aigames\云灯\云灯.html`，对照 `02` 里的行号，找到 `stepRun`、`spawn`、`drawScene` 三处，各读一遍。
3. 改三个地方试试：把 `CATCH_Y` 往上挪 40 像素；把每夜的 `interval` 调小；把 `hpMax` 改成 2。每改一次刷新页面对比手感。
4. 跑一次自检：在地址后面加 `?selftest=1`，看七夜结果是否还是 PASS。

**路线 C｜一周，想做第二款**
1. 路线 B 全部。
2. 读 `05-进阶地图.md`，在 Phaser / Godot 里选一个，跟着官方教程做一个小 demo。
3. 用 `04-上线与分享.md` 把自己的作品发出去，收第一批反馈。

这个包里的 demo 是**教学用最小版本**，故意做得比《云灯》粗糙。它的价值是让你看清骨架，
不是让你拿去发布。真正的成品在 `E:\project\aigames\云灯\`，源码和截图都在那儿，可以随时对照。
