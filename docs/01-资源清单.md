# 资源清单：我实际用了什么

分成三张表：**真用到的**、**只调研没采用的**、**值得你收藏但这次没碰的**。
最后一列「我的用法」说明它在这款游戏里具体解决了什么问题——比收藏链接有用得多。

## 一、真正写进代码的东西

| 名称 | 类型 | 地址 | 我的用法 |
| --- | --- | --- | --- |
| Canvas 2D API | 浏览器原生 | https://developer.mozilla.org/zh-CN/docs/Web/API/Canvas_API | 全部画面都画在一块 720×1280 的画布上，没有用任何绘图库。线条、渐变、椭圆、文字都在这里查。 |
| requestAnimationFrame | 浏览器原生 | https://developer.mozilla.org/zh-CN/docs/Web/API/window/requestAnimationFrame | 游戏主循环。每帧算一次 `dt`（间隔秒数），所有运动都乘 `dt`，所以帧率高低不影响速度。 |
| Web Audio API | 浏览器原生 | https://developer.mozilla.org/zh-CN/docs/Web/API/Web_Audio_API | 音效全部实时合成：接住是短促的三角波，黑雾是低频噪，燃灯是上升音阶。**没有一个音频文件**。 |
| localStorage | 浏览器原生 | https://developer.mozilla.org/zh-CN/docs/Web/API/Window/localStorage | 存档（进度、光屑、最高连击）。键名 `yundeng.save.v1`。 |
| SVG feTurbulence | 浏览器原生 | https://developer.mozilla.org/zh-CN/docs/Web/SVG/Element/feTurbulence | 画面上那层很细的胶片颗粒，一行 CSS 的 `background-image: url("data:image/svg+xml,...")` 做出来的，不是图片。 |
| Noto Serif SC / Noto Sans SC | 开源字体（SIL OFL） | https://fonts.google.com/noto | 中文标题用衬线（Noto Serif SC），正文用黑体（Noto Sans SC）。字体文件走 `miaoda.feishu.cn/fonts/css2` 镜像站加载，避免直连 Google 在部分网络下打不开。 |
| Pillow | 开源库（MIT-CMU） | https://python-pillow.org/ | 把两张 3.9MB 的插画压成 270KB/224KB 的 JPEG。命令就是 `resize` + `save(quality=80)`。 |

> 注意：这张表里没有 Phaser、没有 Pixi、没有任何引擎。因为这一款的需求（单指拖动 + 掉落物 + 七夜流程）
> 用原生 Canvas 写反而更快、文件更小（61KB）。引擎不是必需品，是取舍。

## 二、调研过、这次没用的（选型时至少要知道它们存在）

| 名称 | 类型 | 地址 | 什么时候你应该用它 |
| --- | --- | --- | --- |
| Phaser 4 | 开源引擎（MIT） | https://phaser.io/ ／ 示例库 https://phaser.io/examples | 2D 网页游戏的事实标准之一。需要物理、精灵动画、粒子、场景管理、输入系统时，别自己造。适合做成排行榜类、平台跳跃类。 |
| PixiJS | 开源渲染库（MIT） | https://pixijs.com/ | 只想要「高性能渲染」，物理和游戏逻辑自己写。比 Phaser 轻，比裸 Canvas 省事。 |
| Godot 4 | 开源引擎（MIT，零抽成） | https://godotengine.org/ | 想做真正商业化的 2D 游戏、要可视化编辑器、要导出桌面/移动端。注意：**C# 版不能导出 Web**，要 Web 就用 GDScript。 |
| Bevy | 开源引擎（Rust，MIT/Apache-2.0） | https://bevyengine.org/ | 技术向、模拟密集型、想用 ECS 架构。学习曲线陡，别用它做第一款。 |
| Macroquad | 开源库（Rust，MIT/Apache-2.0） | https://github.com/not-fl3/macroquad | Rust + WebAssembly 的最短路径，API 极简，适合练手。 |
| Dora-SSR | 开源引擎（MIT） | https://github.com/IppClub/Dora-SSR | 带 Web IDE 的 2D 引擎，号称「做 2D 游戏的魔兽争霸编辑器」，适合关卡/学习型项目。 |
| Axmol | 开源引擎（MIT） | https://github.com/axmolengine/axmol | Cocos2d-x 的现代替代，C++/Lua，跨平台到移动端和 WebAssembly。 |
| OpenGame | 学术项目（AI 生成游戏） | 关键词搜 `OpenGame` + `MMLab` + `web game agent` | 香港中文大学 MMLab 那类「用自然语言生成可玩网页游戏」的研究框架。实测意图达成率约 65%，**不能替代人工调平衡**，但可以拿来看「AI 怎么拆游戏」。 |

## 三、值得收藏的素材站与工具（这次没用，下次一定用得上）

| 名称 | 类型 | 地址 | 用途 |
| --- | --- | --- | --- |
| Kenney | 免费素材（CC0，可商用） | https://kenney.nl/assets | 上万件 2D/3D 素材和音效，CC0 意味着不用署名、随便改。做原型首选。 |
| OpenGameArt | 社区素材（许可证各异） | https://opengameart.org/ | 找美术/音乐，**每个素材要看许可证**，CC-BY 要署名，GPL 素材会污染你的项目。 |
| Tiled | 开源地图编辑器（GPL） | https://www.mapeditor.org/ | 做关卡地图，导出 JSON 给引擎用。 |
| Piskel | 开源像素画工具 | https://www.piskelapp.com/ | 浏览器里画像素角色和动画。 |
| Krita / Inkscape | 开源绘图（GPL） | https://krita.org/ ／ https://inkscape.org/ | 位图 / 矢量，替代 PS 和 AI。 |
| Audacity | 开源音频（GPL） | https://www.audacityteam.org/ | 剪辑音效、批量转格式。 |
| Game Programming Patterns | 免费在线书 | https://gameprogrammingpatterns.com/ | 游戏开发的设计模式圣经（状态机、对象池、组件、更新方法）。免费网页版，中文有民间译本。 |
| MDN 游戏开发专栏 | 官方文档 | https://developer.mozilla.org/zh-CN/docs/Games | 从 Canvas 到物理到发布，系统且准确。 |
| Chrome 无头模式 | 浏览器自带 | 本地命令行 `chrome --headless=new --screenshot=...` | 我用它给游戏逐屏截图、跑自检，**不开窗口也能验收画面**。`04` 里有完整命令。 |

## 四、分发平台（决定你能不能被看见）

| 平台 | 门槛 | 地址 | 备注 |
| --- | --- | --- | --- |
| itch.io | 几乎零门槛 | https://itch.io/ | 独立游戏首选，网页游戏可直接内嵌运行，也能收打赏。 |
| Poki | 需要审核 + 排他协议 | https://developers.poki.com/ | 流量大（自称月活上亿），但合同里有 5 年 Web 排他条款（另一处写 7 年），**签之前一定看原文**。 |
| CrazyGames | 需要审核 | https://developer.crazygames.com/ | 月活五千万级，要求 SDK 接入（登录、广告、存档）。 |
| 豆包 HTML 托管 | 平台能力，非开源 | 本次发布用的就是它 | 一条命令把单文件 HTML 变成可访问链接，自动打包同目录 `assets/`。这是平台功能，不是开源项目，换平台时不能指望有等价物。 |

## 怎么用这张清单

不要一次全看。正确顺序是：**先做出来，再按需要补**。
做《云灯》时我只查了 Canvas 和 WebAudio 两个文档页；Phaser、Godot 这些是选型阶段看的，
用完就放下——它们在你的「下一个项目」里才会真正值钱。
