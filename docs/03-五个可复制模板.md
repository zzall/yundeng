# 五个可复制的模板

这五段是《云灯》和两个 demo 里反复用的写法。直接抄进你的项目，改参数就行。

## 模板 1｜画布骨架：虚拟坐标 + 高清适配

```html
<div id="stage"><canvas id="cv"></canvas></div>
<style>
  #stage{
    position:relative;height:100vh;aspect-ratio:9/16;margin:0 auto;
    max-width:100vw;overflow:hidden;background:#050B0F;touch-action:none;
  }
  #cv{display:block;width:100%;height:100%}
</style>
<script>
var W = 720, H = 1280;
var cv = document.getElementById('cv'), ctx = cv.getContext('2d');
function fit(){
  var dpr = Math.min(2, window.devicePixelRatio || 1);   // 封顶 2，别让 3x 屏拖垮性能
  cv.width = W * dpr; cv.height = H * dpr;
  ctx.setTransform(dpr, 0, 0, dpr, 0, 0);                // 之后一切照 720×1280 画
}
fit();
</script>
```

要点：**逻辑坐标永远 720×1280**，`setTransform` 一次把物理像素和逻辑像素分开。
不做这一步，Retina 屏上所有文字和细线都是糊的。

## 模板 2｜主循环（唯一正确的写法）

```js
var last = 0;
function loop(ts){
  requestAnimationFrame(loop);
  if(!last) last = ts;
  var dt = Math.min(.05, (ts - last) / 1000);   // 封顶 0.05s，防止切后台回来瞬移
  last = ts;
  if(paused) return;                            // 暂停 = 不更新逻辑，画面照旧
  update(dt);
  render(dt);
}
requestAnimationFrame(loop);
```

反例提醒：用 `setInterval(fn, 16)` 做游戏循环，在 144Hz 屏上会抖，在后台会被节流到 1 次/秒。

## 模板 3｜下落物 + 「奖励框 ≠ 伤害框」

```js
var CATCH_Y = H - 210;

function updateObject(o, dt, player){
  o.y += o.vy * dt;

  if(o.y >= CATCH_Y && o.y <= CATCH_Y + 92){        // 92px 的判定带，给一点宽容
    var dx = Math.abs(o.x - player.px);
    var reach = o.type === 'bad' ? 52 : player.half; // 伤害用窄框，奖励用宽框
    if(dx <= reach + o.r * .5){
      if(o.type === 'bad') damage(player); else collect(player, o);
      o.done = true;
    }
  }
  if(o.y > H + 60) o.done = true;                    // 出界回收，必写，否则数组无限涨
}
```

这是最容易写错的一处。**同一套判定框同时管奖励和惩罚，升级就会变成负收益。**

## 模板 4｜程序化音效（三行起手）

```js
var actx = null;
function audioInit(){                    // 必须在用户第一次点击/触摸里调用
  if(!actx) actx = new (window.AudioContext || window.webkitAudioContext)();
  if(actx.state === 'suspended') actx.resume();
}
function beep(freq, dur, type, gain){
  if(!actx) return;
  var o = actx.createOscillator(), g = actx.createGain();
  o.type = type || 'triangle';
  o.frequency.value = freq;
  g.gain.setValueAtTime(gain || .12, actx.currentTime);
  g.gain.exponentialRampToValueAtTime(.0001, actx.currentTime + dur);  // 一定要衰减到极小的正数
  o.connect(g); g.connect(actx.destination);
  o.start(); o.stop(actx.currentTime + dur);
}
beep(520 + streak * 18, .12, 'triangle', .1);   // 连击越高音越高
```

两个铁律：① 浏览器禁止没有用户手势就出声，默认静音 + 首次点击再初始化；
② 增益必须 `exponentialRampToValueAtTime` 到一个接近 0 的正数（不能是 0），否则会有爆音。

## 模板 5｜种子随机 + 机器人自检（难度调平神器）

```js
function mulberry32(a){                       // 固定种子的伪随机，可复现
  return function(){
    a |= 0; a = a + 0x6D2B79F5 | 0;
    var t = Math.imul(a ^ a >>> 15, 1 | a);
    t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t;
    return ((t ^ t >>> 14) >>> 0) / 4294967296;
  };
}

function simulate(nights, seed){
  for(var n = 1; n <= nights; n++){
    var r = newRun(n, seed, upgrades);        // 不渲染，只有数据
    while(!r.done){
      stepRun(r, 1/60, botTarget(r));         // 用机器人代替人手
    }
    console.log('第' + n + '夜', r.score, r.hp, r.catches, r.hits, r.win ? 'WIN' : 'LOSE');
  }
}
```

机器人不用很聪明，只要「中等水平」：先躲 0.5 秒内会砸到头的危险物，否则去接最靠下的奖励。
跑完七夜约 3000 步，3 秒出结果，比你自己试玩快 200 倍。
