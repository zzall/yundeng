# 上线与分享：从「本地双击」到「发出去」

四个台阶，每上一个台阶门槛都会变高。别跳级。

## 台阶 1：本地能被打开

双击 `E:\project\aigames\云灯\云灯.html` 就行。注意两点：

- 图片必须用**相对路径**（`assets/title.jpg`），写成 `file:///E:/...` 的绝对路径发出去就裂图。
- 浏览器不允许 `file://` 页面用 `fetch` 读本地 JSON。要读数据就把数据内联进 JS。

自检命令（Windows PowerShell，用来在不开窗口的情况下验收画面）：

```powershell
# 截一张 720×1280 的图，看构图对不对
& 'C:\Program Files\Google\Chrome\Application\chrome.exe' --headless=new --disable-gpu `
  --hide-scrollbars --window-size=720,1280 --virtual-time-budget=2000 `
  --screenshot="E:\project\aigames\云灯\_shots\play.png" `
  "file:///E:/project/aigames/云灯/云灯.html?probe=play:3"

# 把页面跑完后输出 DOM，用来看自检结果
& 'C:\Program Files\Google\Chrome\Application\chrome.exe' --headless=new `
  --virtual-time-budget=3000 --dump-dom `
  "file:///E:/project/aigames/云灯/云灯.html?selftest=1"
```

这套做法值得学：**画面靠截图看，逻辑靠文字看**，两件事都不需要你手动点 200 下。

## 台阶 2：同一局域网能玩

```powershell
cd 'E:\project\aigames\云灯'
python -m http.server 8080
```

手机连同一个 Wi-Fi，访问 `http://<你电脑的局域网 IP>:8080/云灯.html`。
这一步能立刻发现手机上的问题：字号太小、按钮点不到、横屏错位。

## 台阶 3：公网可访问（静态托管）

单文件 HTML + 一个 assets 目录，属于「纯静态」，随便哪个都能放：

| 平台 | 免费额度 | 适合 |
| --- | --- | --- |
| Cloudflare Pages | 无限带宽 | 首选，全球 CDN，部署就是连 Git 仓库或拖文件夹 |
| Vercel | 个人免费 | 部署最快，但国内访问偶尔不稳 |
| GitHub Pages | 免费 | 已有 GitHub 就用，`仓库名.github.io` 直接访问 |
| itch.io | 免费 | 想被玩家发现就用它，网页游戏能内嵌运行 |

发布前自查：

- **单个 HTML ≤ 20MB**，全部素材加起来别超过 10MB，手机流量用户会谢你。
  本次两张插画从 7.5MB 压到 490KB，用的是 Pillow：

```powershell
$env:PYTHONPATH='E:\project\aigames\工具\py'
python 'E:\project\aigames\工具\py\compress_art.py'
```

- **字体走镜像站**，不要直连 `fonts.googleapis.com`：部分网络下打不开，页面会白屏两秒。
- 加 `favicon`，分享到微信/群里才不像半成品。

## 台阶 4：上小游戏平台（Poki / CrazyGames）

这一步是商业决策，不是技术决策。要点：

- **要接 SDK**：登录、广告、排行榜、存档，平台会要求你用它的 SDK 而不是自己的 localStorage。
- **要看排他条款**：Poki 的条款里出现过「Web 端 5 年排他」和另一处「7 年」的不一致表述，
  签之前把原文逐条读完，尤其是「能不能同时上架别家」。
- **要能过审**：加载 ≤ 3 秒、无外部跳转、移动端可玩、崩溃率极低。
  这些东西在你本地测不出来，必须真机 + 弱网。

本次发布的链接是走豆包 HTML 托管（平台能力，不是开源方案），
默认**仅创建者可见**；要发给别人玩，得在页面设置里把可见范围改成「获得链接的人可访问」。

## 移动端必查清单

```
[ ] <meta name="viewport" content="width=device-width, initial-scale=1">  不加 viewport-fit 也行，但别禁止缩放
[ ] 容器 touch-action:none        否则手指一拖，页面跟着滚
[ ] 音频默认静音，首次点击再初始化  否则 iOS Safari 直接静音
[ ] 按钮不小于 44×44px
[ ] 画布用 aspect-ratio 或 vh 适配，不要写死 px 高度
[ ] 横屏/竖屏切换后重新 fit()
[ ] 字体加载失败时有系统字体兜底：font-family: "Noto Serif SC", serif
```

## 分享文案怎么写

`share()` 里用的是三段信息：**做了什么 + 数字 + 一句情绪**。

> 我在《云灯》里守到第 7 夜，接住了 412 粒光屑，最长连击 34。灯还亮着。

数字让朋友有比较欲，最后一句让没玩过的人好奇。写「快来玩我的游戏」基本没人点。
